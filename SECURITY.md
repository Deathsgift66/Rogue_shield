# Responsible Vulnerability Reporting

Please report vulnerabilities affecting RogueShield itself through **GitHub's private vulnerability-reporting feature**, if enabled. If it is unavailable, open a non-sensitive issue asking for a private reporting channel. **Do not post exploitation instructions, real credentials, customer data or unpublished vulnerability details in a public issue.** No email address is invented for this project.

Useful report details include impacted version/commit, precise component, steps to reproduce with *synthetic* inputs, impact and a suggested mitigation. Please do not test infrastructure or accounts you do not own or have authority to assess.

We aim to triage responsibly and coordinate fixes and disclosure, but no response time or professional support SLA is guaranteed. This policy does not confer permission to assess GitHub, other projects, downstream adopters or third-party infrastructure. Any future project-run disclosure safe harbor must identify the **exact project-owned assets in scope**; none are listed here.
