# Privacy and Telemetry

The v0.3 community CLI **does not make network connections, collect telemetry or transmit scan results**. Reports are written locally at the operator's request. The guided setup records the selected profile/environment and acknowledgement in a local JSON file, not a central account system.

Local analysis may include path names, route identifiers and other metadata in report outputs. Do not publish reports without checking for confidential content. No automatic retention, deletion or encryption is implemented for files users generate; the operator controls them.

This statement concerns the CLI code only. GitHub, downloads, host infrastructure or any future website may process information under their own policies. Any future hosted, commercial or opt-in telemetry service requires its own accurate privacy documentation and retention policy.
