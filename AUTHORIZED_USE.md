# Authorized Use Guidance

RogueShield is designed for legitimate defensive assessment, training with synthetic fixtures, education, and analysis of software under the operator's control or with explicit permission from the owner.

A public endpoint, accessible GitHub repository, demonstration application or reachable IP address does **not** confer permission to conduct intrusive testing. Before any future network assessment, operators should document the scope, authorizing person or organization, permitted techniques, timing, exclusions, data handling, emergency contact and stop conditions. The official v0.3 application is local-file-only and does not send test traffic.

A typed authorization statement is an acknowledgement; **it is not independent evidence of ownership, permission, or legal authority**. Future network functionality must independently enforce scoped destinations, expiration, quotas and capabilities and obtain stronger target-side authorization where practical.

**Relationship to the MIT license:** This document states project intent and recommended conduct, not an additional copyright license. It does not restrict, supersede, or add conditions to the permissions granted by MIT. Users remain responsible for applicable law. The maintainer does not authorize testing anyone else's systems.
