# RogueShield Roadmap

**Implemented in 0.3:** CLI setup/levels, strict offline-only policy, static Python and OpenAPI review, synthetic ledger consistency, human-readable text/HTML/JSON reports, offline 700-virtual-agent quotas, scope declarations validation, basic safety tests, MIT/authorized-use/privacy/security docs.

**0.4 — Usability:** desktop UI, packaged install, per-rule references, guided remediation, report filtering, baseline comparison, project auto-detection for additional ecosystems, accessible localization.

**0.5 — Defensive analysis:** richer rule catalog; configurable code rules and contract inventory; dependency/SBOM analysis; secrets checks that never store token values; game-specific state machine fixtures; policy coverage dashboards; redaction validation.

**0.6 — Authorized staging:** independently reviewed, opt-in staging-only request broker; cryptographically bound authorization proof, exact origins/IP pinning, redirect denial, conservative budgets and abort switch; read-only tests only.

**0.7 — Game/AI defenses:** cross-player ownership matrices, market/currency/item invariants, anti-bot policy fixtures, bounded artificial-world concurrent scenarios, WebSocket authorization planning. Keep 700-actor simulations offline unless an isolated disposable target is independently verified and explicitly approved.

**0.8+ — Operational assurance:** signed releases, artifact provenance, component inventory, SBOM, audit trail, safe optional integrations with established defensive scanners, security review and CI hardening. Optional AI can propose constrained review tasks but must not receive unrestricted sockets, credentials or shell access.

**1.0 gate:** repeatable tests, independent security review of policy/broker, documented false positives, install support, safe recovery, legal/ownership review, an abuse response process and a maintainer-supported disclosure channel. No claims of complete security or litigation immunity.
