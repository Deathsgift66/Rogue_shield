# Contributing

RogueShield is MIT-licensed. Contributions intended for inclusion should be offered under MIT, with rights to contribute. Use **DCO 1.1 sign-offs** (`git commit -s -m "Description"`) to attest provenance; see https://developercertificate.org/.

**Never upload** proprietary software, private game source, credentials, leaked code, player data, internal audits, client findings, malware or third-party confidential information. Use fixtures invented for the test. AI-generated contributions require human review, provenance inspection and explanation of any third-party code.

Supply tests for all behavior changes, especially safety guards. Security-sensitive policy, network scope, credentials, automation, mutating actions and dependency changes need maintainer security review. Avoid new dependencies where the standard library suffices; record required licenses.

Please report vulnerabilities using SECURITY.md before public discussion. This is a community engineering guide, not an additional restriction on MIT rights.
